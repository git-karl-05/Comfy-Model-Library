# Edit controls

Copy and Expand use the current unsaved field values. Closing the expanded editor
preserves edits and returns focus to the original control. Clipboard fallback is
available when the browser clipboard API cannot be used.

Removing a LoRA default preview clears its reference without deleting associated
image records or physical files. A submitted replacement takes precedence over
removal. Pose edits retain the remaining previews and promote the next preview
when the default is removed.
